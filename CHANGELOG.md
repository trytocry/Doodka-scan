# Изменения

## 1.3.0 — 11.11.2026

- Публичный репозиторий `trytocry/Doodka-scan` и сборка Windows-релизов в GitHub Actions.
- Установочная версия NSIS с автообновлениями из GitHub Releases. Переносимая версия остаётся без автообновлений.
- Автоматическая проверка при запуске и каждые 6 часов, фоновая загрузка, установка при закрытии или по кнопке перезапуска.
- Индикация версии и состояния обновления, ручная проверка, обработка отсутствия сети. В приложение не включаются токены GitHub.
- Локально прошли три модульные проверки обновлений и девять проверок приложения. Физическая печать не выполнялась.

## 1.2.0 — 11.11.2026

- Добавлены распознавание, PDF и печать Data Matrix, включая GS1 Data Matrix.
- Сохраняется исходная матрица символа, а не только отображаемый текст. Перед использованием она повторно считывается, сравниваются байты, ECI, идентификатор символики и данные последовательности.
- Прямоугольные символы центрируются в квадратной области; ограничения размера и разрешения печати сохраняются.
- Девять автотестов прошли. Дополнительно проверены обычный Data Matrix, GS1 с разделителями и двоичный код; сравниваются данные из предпросмотра и печатной раскладки, размер и количество PDF-страниц. Физическая печать на TSC TE200 и конкретное фото пользователя пока не проверены.
- Откат: предыдущие EXE сохранены в `release`.

## 1.1.1 — 11.11.2026

- Дополнительный распознаватель ZXing-C++ встроен в EXE, без загрузок из интернета.
- Большие фотографии проверяются в большем разрешении и по участкам, чтобы сохранять детали небольшого QR.
- Добавлен просмотр полученного фото; при ошибке он раскрывается автоматически.
- Data Matrix определяется отдельно и сопровождается объяснением, что его печать пока не поддержана.
- Шесть автотестов прошли, включая небольшой повёрнутый QR в большом JPEG и отдельную проверку нового распознавателя без сети. Исходное проблемное фото пользователя не предоставлено; исправление именно на нём не подтверждено.

## 1.1.0 — 11.11.2026

- Кнопка «Печать»: список установленных принтеров и системный диалог, страницы 20 × 20 мм, масштаб 100%, без полей, одна этикетка на страницу.
- Кнопка «Добавить с телефона»: временная QR-ссылка, мобильная страница съёмки/выбора фото, передача по локальной сети напрямую в приложение.
- Ссылки отключаются при закрытии окна, выходе из приложения или через 15 минут. Проверяются тип и объём файла, случайный токен, источник запроса.
- Сохранение PDF и работа с локальными фотографиями без сети сохранены.

Проверка: сборка успешна, пять автотестов прошли. Печатный вызов проверен с подменой системного принтера; настоящая печать не выполнялась. Загрузка проверена через мобильную страницу в Chromium на этом компьютере; реальные телефоны и разрешения брандмауэра требуют проверки на месте.

Откат: предыдущий переносимый EXE 1.0.0 сохранён в папке `release`. Закрыть программу и вернуть его вместо текущего файла рабочего стола.

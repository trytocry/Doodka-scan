QR Этикетка 1.3.1 — QR и Data Matrix с фотографии в наклейки 20 × 20 мм.

- Фото с компьютера или телефона по локальной сети.
- Сохранение PDF и печать с выбором принтера.
- Поддержка Data Matrix и GS1 Data Matrix с сохранением исходных данных.
- Автоматическая проверка и загрузка обновлений из GitHub Releases.

Для автоматических обновлений скачайте **QR-Etiketka-Setup-1.3.1-x64.exe** и установите программу один раз. Обновления устанавливаются при закрытии приложения; также доступна кнопка перезапуска.

Версия **Portable** работает без установки, но не обновляется автоматически. Старые переносимые версии 1.2.0 и ниже нужно заменить установочной версией вручную.

Windows 10/11 x64. Установщик не подписан сертификатом издателя. Физическую печать проверяйте на вашем принтере с носителем 20 × 20 мм и масштабом 100%.

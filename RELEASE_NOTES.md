# QR Duplicator 1.6.0

Профили бумаги теперь связаны с настоящими настройками печати Windows. Откройте «Профили бумаги в драйвере», выберите принтер и формат, затем нажмите «Применить в Windows». Для создания формата используйте кнопку «Создать / изменить в драйвере».


- Добавлен выбор настоящих профилей бумаги из драйвера Windows.
- «Применить в Windows» сохраняет профиль в настройках печати текущего пользователя и считывает результат обратно.
- Создание и изменение форматов доступны через штатное окно драйвера, открываемое из программы.
- Для Seagull размеры читаются через PrintTicket, без добавочного смещения стандартного списка бумаги.
- Поддерживаются этикетки 18 × 18 мм; диапазон каждой стороны теперь 18–100 мм.
- Выбранный принтер запоминается для печати, размеры этикетки синхронизируются с применённым профилем.

# QR Duplicator 1.6.1

Активный профиль бумаги теперь виден прямо на главном экране вместе с принтером и реальными размерами.


- На главном экране показаны принтер, активный профиль бумаги и фактические размеры из драйвера Windows.
- Данные обновляются при запуске, после смены профиля, при возвращении в окно и по кнопке «Обновить».
- При ошибке чтения отображается сообщение о недоступности, а не устаревший профиль.
- Фоновое чтение профиля не меняет настройки драйвера и не блокирует печать.

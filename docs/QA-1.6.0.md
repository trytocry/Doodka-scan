# Проверка интеграции профилей бумаги — 15.11.2026

- Локально пройдены сценарии выбора, ошибки, отмены, обновления списка, синхронизации размеров и предпочтительного принтера. В этих интерфейсных тестах ответы драйвера моделируются; задания физическому принтеру не отправляются.
- Проверены PDF и печатная разметка для 18 × 18 мм, а также прежние квадратные и прямоугольные размеры.
- На реальном TSC TE200 / Seagull 2024.2 прочитан список через Winspool + PrintTicket. Проверено переключение профиля 260 → 257, чтение сохранённого выбора новым процессом, затем возврат 257 → 260. Исходный размер 20 × 20 мм восстановлен.
- Чтение реального драйвера проверено через IPC из собранного Windows EXE с внешними компонентами PowerShell/C#.
- Создание формата выполняет родное окно драйвера DocumentProperties; программа не редактирует закрытый реестр форматов Seagull и не выдаёт локальные шаблоны за профили Windows. В автоматических тестах этот диалог моделируется.
- Для Seagull стандартный DEVMODE сообщал 22,5 мм вместо размера этикетки 20 мм. Использован PrintTicket, соответствующий настройкам в интерфейсе драйвера.
- Физическая печать и калибровка ленты не выполнялись. Новый профиль бумаги пользователь создаёт в штатном окне драйвера.

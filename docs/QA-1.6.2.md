# Проверка 1.6.2 — 17.11.2026

## Исправление
Задание больше не проходит через Electron webContents.print и второй диалог выбора принтера. Windows GDI получает полный DEVMODE выбранного по размерам профиля, включая закрытые поля производителя. Отдельные страницы рисуются в физических координатах, число копий драйвера равно 1. Настройки Windows по умолчанию не записываются.

## Реальный TSC TE200, без расхода бумаги
- Список профилей читается через Windows/PrintTicket. Профиль id 260 с названием 18x18 имеет реальные размеры 20 × 20 мм.
- probe-print создаёт тот же GDI-контекст, что рабочая печать, но выходит до StartDoc. Для 20 × 20 мм выбран id 260, разрешение 203 × 203 dpi.
- Нативная ширина DC около 22.65 мм включает дополнительную область Seagull; размер этикетки берётся из PrintTicket, а не из этой ширины.
- Запрос 18 × 18 мм отклонён: такого фактического размера среди профилей нет.
- Повторное чтение подтвердило неизменность пользовательских настроек драйвера.

## Ограничения
Физическое задание не отправлялось. Качество, положение и считывание напечатанного кода нужно подтвердить пробной этикеткой. Тест Electron подменяет отправку, проверяя передачу матрицы, размеров и количества в native helper, без расхода бумаги.
